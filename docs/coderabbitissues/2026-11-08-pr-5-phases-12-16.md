## Findings

### CR-01 — Terminal key regenerated on retry

- **Summary:** `enrollTerminal` overwrote the Ed25519 key after partial redeem → cloud `INSTALLATION_MISMATCH`.
- **Disposition:** `fix`
- **Resolution:** Reuse stored credential whenever `credentialRef` + key file exist; resume host-accept/confirm after redeem.

### CR-02 — DPAPI secret on PowerShell argv

- **Summary:** Private key embedded in `-Command` string (process listings / auditing).
- **Disposition:** `fix`
- **Resolution:** Pass secret via stdin; path single-quoted. Interim until native DPAPI FFI.

### CR-03 — Rotate proves only new key

- **Summary:** Anyone who knows public metadata could rotate with a self-signed new key.
- **Disposition:** `fix`
- **Resolution:** Sign canonical rotate message with **previous** private key; web verifies against `previousPublicKey`.

### CR-04–07, CR-22–23, CR-26 — Format / lint CI

- **Disposition:** `fix`
- **Resolution:** Prettier on listed files; remove useless `\[` escape in capabilities parser.

### CR-08 — Wrong-role redeem consumes grant

- **Disposition:** `fix`
- **Resolution:** `expectedRole` on redeem request/contracts; forward migration `20261108120000_redeem_expected_role_and_audit_execute.sql` adds `p_expected_role` and raises `ROLE_MISMATCH` before attempt burn/consume.

### CR-09 — Audit writer EXECUTE for API roles

- **Disposition:** `fix`
- **Resolution:** Same forward migration revokes `anon`/`authenticated` EXECUTE on `polivo_write_admin_audit` and grants `service_role` only.
