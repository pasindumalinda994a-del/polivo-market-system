# Architecture and Business Decision Records

This directory stores approved architecture decisions and significant business-rule resolutions for Polivo Market System.

Unresolved questions remain in `docs/context/progress-tracker.md`. When a question is resolved, create a decision record here and link it from the progress tracker.

Do not create accepted decision records for unresolved questions.

## Record Format

Each record should include:

- Title and identifier
- Status: Proposed, Accepted, or Superseded
- Date
- Context and source
- Decision
- Reasoning
- Consequences
- Related implementation phases

## Naming

Use sequential filenames:

`0001-short-decision-title.md`

Example: `0001-local-sqlite-authority.md`
